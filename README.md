## Devlog

### Activity 1

FloatAnimation script makes fish food to go up and down. When the Start() begin the _timer variable goes to 3.0f because the variable of _switchSpeed is 3.0f, which menas that when it starts it starts to move for 3 seconds. For the Update() it makes FloatAnimation to go up and down, by if the variable is _up, then the food goes up and else it will go down.
